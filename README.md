# Web Application Firewall (WAF)

## Project Overview
A Web Application Firewall built using Node.js and Express.js to monitor incoming web requests and help protect web applications from common attacks.

## Features
- Detects common web attacks such as SQL injection and Cross-Site Scripting (XSS).
- Blocks suspicious IP addresses.
- Supports IP address whitelisting for trusted addresses.
- Records security events.
- Provides an interactive security dashboard.

## Technologies Used
- Node.js
- Express.js
- HTML
- CSS
- JavaScript

## Installation and Setup

1. Clone this repository:
   ```bash
   git clone https://github.com/srlatha-arangi/web-application-firewall.git
   ```

2. Open the project folder:
   ```bash
   cd web-application-firewall
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Start the server:
   ```bash
   node server.js
   ```

5. Open the local URL configured by the application in your browser.

## Project Purpose
This project demonstrates basic web application security, request filtering, IP access control, and security event monitoring.
